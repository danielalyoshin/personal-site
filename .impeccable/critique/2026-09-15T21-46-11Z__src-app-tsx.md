## Overall Impression

The object is excellent and the page around it is fighting it. All four owner reports are confirmed, with one correction: the deck keys do not drift during insertion; the label switches identity at the moment the tape starts moving. The single biggest opportunity is subtraction: fewer prints, fewer captions, one label per key.

## What's Working

- **Preview choreography.** One `preview` state drives the lifted tape, the tube caption, the guide text, and the index card highlight together (`Stage.tsx:107–111`, `Tape.tsx:99–101`, `StudioScene.tsx:176–187`). It teaches clickability without instruction.
- **Honest transport.** The tape clears the rack, turns, seats, and the flap closes before the camera moves to real selectable HTML on the screen plane (`transport.ts`, `StudioScene.tsx:214–229`). Escape returns focus to the originating card.
- **The One Light Rule holds.** Neutral fill reveals geometry; saturation is confined to spines and tube; at 1440×900 the whole studio lands in the first viewport.

## Priority Issues

**[P1] Deck keys carry three competing labels, and swap at the moment the tape moves.** In browse, each key shows a printed cap label ("SOUND", "EJECT", `PlayerButton.tsx:92–99`) plus a second fascia print below it ("SOUND", "EJECT / ESC", `Player.tsx:178–205`). At click, `deckInteractive` flips with `open` (`Stage.tsx:446`), so at t=0 the cap label is replaced by a billboarded HTML label ("OFF", "⏏ EJECT") with a 44px floor (`PlayerButton.tsx:39–41`). During insertion the sound cap is ~35px and the eject cap 37px, so the HTML label overhangs the cap and sits flat over an obliquely viewed fascia. The canvas also snaps from in-flow 1296×550 to fixed 1440×900 in the first 400ms (sound key centre moved from (379,319) to (304,518)), so the whole deck jumps before the mechanism reads. After that the caps hold within 0.1px. **Why it matters:** it is the first thing the visitor watches after committing, and it looks broken. **Fix:** one label per key, printed on the cap, identical in both states; make the HTML button an invisible hit area with an aria-label; show on/off in the status window or a modeled LED; delete the fascia prints; gate interactivity to after insertion; size the canvas before the tape starts. **Command:** `/impeccable polish`.

**[P1] Model print is mostly noise, and every print has two rendering defects.** 29 `Print` planes plus 14 label canvases. Zoom is ~73px/unit at browse, ~116 during insertion, ~221 at playback; a 0.07-unit print is 5 / 8 / 15px tall with ~42% glyph height, so rack numbers, holder cheeks, speaker, headphone stand, plinth, and cassette undersides never reach legibility. Two bugs compound it: non-fitted prints always use a 1024×128 texture regardless of aspect (`geometry.tsx:92–100`), so glyphs stretch horizontally (plinth 3.7×, flap 1.9×, monitor chin 1.8×); and the print material (`geometry.tsx:107–112`: roughness 0.85, metalness 0, smooth) differs from `Solid` (0.82 / 0.12 / flat), so each label sits on a visibly lighter rectangle. The 1.75 pixel-ratio cap (`StudioScene.tsx:515`) then upsamples 14% on 2× displays. **Why it matters:** the print reads as a rendering flaw from every camera and the noise dilutes the few labels that matter. **Fix:** keep only the signature prints (status window, AV–01 model line, spine number and name, idle screen); delete the rest; make surviving prints aspect-correct via the fitted path with a transparent background or matched material; use SDF text (drei `Text`) for the few that must read; allow DPR 2 during playback. **Command:** `/impeccable distill` (inventory) with the rendering fixes in `/impeccable polish`.

**[P1] Shell clutter and misalignment.** Redundant: identity ×5 in the fold, "06" in three treatments, four routes to the same six tapes, a page-level Sound control (`Stage.tsx:401–411`) duplicating the deck key, a decorative clock and "STUDIO 01 / PERSONAL ARCHIVE". Misaligned: four left edges at 72 / 103 / 122 / 149px (column, card text, header text, caption text), three right edges at 1368 / 1352 / 1244px (aside `padding-right:16px` `Stage.module.css:91`; footer nav `margin-right:48px` `:330`), the drag-hint baseline 12px below the caption's, the "↓" floating 18px from its text (`:110`). Mobile: the shell takes 750px before the canvas; the canvas bleed cuts the speaker at the left edge. **Why it matters:** the visitor's eye has nowhere to rest before the artifact, and the misalignments read as carelessness on a site whose claim is craft. **Fix:** remove scene meta, clock, caption number, page Sound, and two of the three counts; one index CTA; flush aside and footer to the 1368 edge; put tools on the caption baseline or in the canvas corner. **Command:** `/impeccable distill`, then `/impeccable layout`.

**[P2] The type system sprawls.** Eight Archivo weights render (400/440/500/550/560/600/650/800), eleven sizes, and a 9px tier that DESIGN.md never lists in its ramp (the ten CLI hits). The arrows ▶ ↓ ↗ ↺ ↔ are fallback-font glyphs because Archivo lacks them, so they mismatch in weight. The ESC hint inside Eject measures 4.2:1. VT323 does not leak into chrome, which is right. **Fix:** four weights (400, 600, 800, VT323 400), six sizes with an 11px floor, SVG icons (the set already in `DeckControls.tsx:9–42`) for every arrow, tabular numerals only where numbers align, ESC hint to ≥4.5:1. **Command:** `/impeccable typeset`.

**[P2] Desktop deep links never show the studio.** `nativePlayback` pins the full-height reader for the whole visit (`Stage.tsx:64–69,121`); verified `sceneReady:true` with `nativeReader:true` on `/project/placeholder-alpha`. Sharing is the success metric, and the shared link hides the hero. **Fix:** once the scene is ready, cross-fade to modeled playback with the tape pre-seated (deep links already begin seated), or render the dimmed studio behind the reader. **Command:** `/impeccable shape` (a behavior decision).
