# personal-site

Daniel Alyoshin's portfolio. Projects are presented as VHS cassettes on a
shelf; selecting one plays its details on a CRT-styled display — modern-clean
execution, retro subject matter.

- `PLAN.md` — staged implementation plan
- `PRODUCT.md` — product context (audience, positioning, constraints)
- `CLAUDE.md` — working rules for AI-assisted development

## Develop

```sh
npm install
npm run dev
```

## Scripts

| Script                 | Purpose                       |
| ---------------------- | ----------------------------- |
| `npm run dev`          | Start the Vite dev server     |
| `npm run build`        | Type-check + production build |
| `npm run preview`      | Serve the production build    |
| `npm run lint`         | ESLint                        |
| `npm run format`       | Prettier (write)              |
| `npm run format:check` | Prettier (check only)         |
